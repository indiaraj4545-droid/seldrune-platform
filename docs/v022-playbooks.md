# Seldrune v0.22 operational playbooks

Seldrune promotes a repeated reflection pattern only after at least two completed runs support it.
Promoted playbooks are stored in organization memory and can guide later planning.

Owner instructions remain authoritative. Learned playbooks are advisory planning inputs and use the same bounded adaptive overlay introduced in v0.21. They do not silently replace owner constraints or create a new hard execution gate.

The Command Monitor shows promoted playbooks separately from raw outcome memory and reflection memory so the owner can see when durable learned behavior affected a plan.
